# Эскизы экранов (неделя 2)

Низкодетальные wireframe-эскизы. Для сдачи можно заменить на скриншоты из Figma или фото рисунка.

## 1. Библиотека (телефон)
```
┌──────────────────────────┐
│ Моя библиотека        ⟳  │
│ (Все)(Хочу)(Читаю)(Проч.)│
│ ┌──────────────────────┐ │
│ │ ▭  Dune              │ │
│ │ ▭  Frank Herbert     │ │
│ │    ▓▓▓▓▓▓░░░░ 60%    │ │
│ └──────────────────────┘ │
│ ┌──────────────────────┐ │
│ │ ▭  Идиот             │ │
│ │ ▭  Ф. Достоевский    │ │
│ │    [✓ Прочитано]     │ │
│ └──────────────────────┘ │
│                [+ Добавить]│
├──────────────────────────┤
│ 📚Библ.  🔍Поиск  📊Стат.  ⚙│
└──────────────────────────┘
```
Планшет / альбомная ориентация: слева `NavigationRail`, список превращается в сетку карточек.

## 6. Настройки · 7. Вход / регистрация
Настройки: тема (системная / светлая / тёмная), язык (RU/EN), цель на год, push, аккаунт.
Вход: логотип, email, пароль, «Войти», «Продолжить с Google», ссылка на регистрацию.
